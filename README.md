# مرآة أصوات التلاوة — نور المسلم

سور مضغوطة لكل قارئ تُستخدم مصدرًا أولًا للتنزيل في تطبيق نور المسلم (بلاغ المالك: الاصوات تكون على سيرفر على جت هب علشان نضمن ان التحميل يتم صح).

- الإصدار: `audio-v1` — الأصول بأسماء `مجلد-السورة.zip` وبداخلها الآيات بأسمائها المعتمدة `sssaaa.mp3`.
- البناء: workflow «مرآة أصوات التلاوة» يدوي التشغيل (فهرس زوجٍ أو مجلداتٍ بعينها) — والموجود يُتخطى.
